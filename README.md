# K.K Trip 2026

Malayalam trip budget page for Mountain Peak Resort, Kakkadampoyil.

## Run

Open `index.html` in a browser. No installation or build step is required.

## Features

- Complete budget summary and all 13 group breakdowns
- Per-person resort and food costs
- Green received amounts and red outstanding balances
- Group search, responsive layout, and reduced-motion support
- Mountain banner and subtle animations

HTML, CSS, and JavaScript are contained in `index.html`. Fonts are loaded from Google Fonts, with local fallbacks.

## Editing

The `data` array contains group members, child counts, and advances. Summary figures and notices are written in the HTML; update those too if the budget changes.

This private repository contains trip participants and payment amounts.
